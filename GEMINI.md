# Gemini -- Boilerworks Astro Site

Primary conventions doc: [`bootstrap.md`](bootstrap.md)

Read it before writing any code.

## Quick Reference

- Astro 6, Tailwind CSS v4, Vitest
- Content collections in `src/content/blog/` (Markdown/MDX)
- Schemas in `src/content.config.ts` (Zod validation)
- Theme tokens in `src/styles/global.css` (`--brand-*` CSS properties)
- No Docker -- use `npm run dev` for local development
- Run `npm run lint` before committing
