# Boilerworks Astro Site

> Edge template -- Astro on Cloudflare Pages. Content sites, blogs, docs, marketing. SSG + SSR hybrid.

**Status:** Planned

Astro content-first site on Cloudflare Pages. Islands architecture with interactive components from any framework (Svelte, React, Vue). SSG by default with opt-in SSR for dynamic pages. Markdown/MDX content collections, Tailwind CSS styling. Ideal for blogs, documentation sites, marketing pages, landing pages, and any content-heavy site.

**Edge template** -- production deployment targets Cloudflare Pages, not Docker. SSG + SSR hybrid, content-first.
